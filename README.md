# Home MCP

개인 홈 서버를 ChatGPT의 도구로 연결한다. 별도 채팅 UI와 스케줄러는 만들지 않는다.

## 진행

- 1단계: 인증, MCP 연결, 작업 공간 제한, 파일·짧은 명령 실행.
- 2단계: Git·긴 작업·Docker·서버 관리와 작업별 관리자 승인.
- 3단계: 설치/업데이트 명령, 자동 시작, HTTPS 연결과 실제 서버 점검.

현재는 1단계 구현 중이다. 아직 설치·배포하지 않았으며, 완성 후 서버에서 확인한다.

## 고정 기준

- 작업 공간: `/mnt/storage/dev`
- 소스 전달 위치: `/mnt/storage/dev/server` (일반 MCP 작업에서 쓰기 금지)
- 접속 예정 주소: `https://k9m2x7p4vq3b8z1.12190529.xyz/mcp`
- 외부는 HTTPS 443만 기본 사용. 내부 실행 포트를 인터넷에 직접 개방하지 않는다.
- `.gitignore` 없음. 소스·예제·설치 정의는 추적하고 실제 비밀값·로그·DB는 레포 밖에서 생성한다.
